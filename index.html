HEXA

A highly secure, perceptual-hash image blocklist for Discord. Stop scam images, phishing QR codes, and malicious links in their tracks—even if attackers try to resize or re-compress them.

Add to Discord View Commands

Overview

ImgBan uses pHash and dHash algorithms to create a unique digital fingerprint of scam images.

If a user posts an image that matches the blocklist, the bot instantly deletes it, DMs the user (in case their account is compromised), applies a punishment, and logs the incident to your admin channel. Built with an interactive UI, a dynamic custom-emoji engine, and multiple layers of scanning.

Features

Free Tier

Essential protection for every server.

  • Perceptual Hashing (pHash/dHash)
  • Automated Image Deletion
  • DM Notifications to Users
  • Security Logging to Admin Channels

Premium Tier

Advanced scanning and threat prevention.

  • Advanced Punishments (Timeout, Softban, Ban)
  • Malicious Link & Domain Scanning
  • Phishing QR Code Detection

Developer Features

Global control for the bot owner.

  • Global Blocklist (Push to all servers)
  • Premium Management via DM/Server
  • Global Ban/Unban Commands

Bot Interface

Experience the sleek, interactive Discord UI.

Image Blocking
;imgban [note] — Reply to an image to block it.
;imgunban — Remove a blocked image.
;imglist — Browse blocked image hashes.
Configuration
;imgconfig — View current settings.
;imgconfig punishment — Set punishment.
;imgconfig logchannel <#channel> — Set log channel.
;imgconfig threshold <0-16> — Set match strictness.
;imgconfig dm — Toggle DM warnings.
