System Limitations

  • Bot/Webhook Exemption: Messages sent by bots/webhooks are not scanned.
  • Edits: Edited messages are scanned, but deleted messages cannot be recovered.
  • SSRF Protection: Linked images are only downloaded if the URL resolves to a safe, public IP.
  • Emoji Rendering: Custom emojis won't render for users who don't share a server with them.
  • Profile Cards: Unsupported font characters fallback to "Hexa User". Emojis in names require pilmoji.
