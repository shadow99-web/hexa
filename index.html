Command_Registry

Public_Functions Free
;imgban [note] Reply to an image to add its hash to the blocklist.
;imgunban Remove a blocked hash from the server.
;imglist Browse the server's blocked hashes.
;imgconfig View current server settings.
;imgconfig punishment Set punishment action.
;imgconfig logchannel <#channel> Set the security log channel.
;imgconfig threshold <0-16> Set matching strictness (Default: 5).
;imgconfig dm Toggle DM warnings.
Premium_Functions Premium
;imgconfig punishment Unlocks higher-tier punishments.
;qrban Block a QR code by its payload.
;qrunban Remove a blocked QR payload.
;qrlist Browse blocked QR payloads.
;imgconfig qr Toggle QR scanning.
;domainban Block a URL domain.
;domainunban Unblock a domain.
;domainlist Browse blocked domains.
;imgconfig links Toggle link scanning.
Root_Functions Dev
;globalban [note] Block image across all servers.
;globalunban Remove hash from global blocklist.
;globallist View the global blocklist.
;premium add [days] Grant premium access.
;premium remove Revoke premium access.
